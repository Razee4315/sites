02 — FLAKY-TEST QUARANTINE

A test that flips three times stops blocking merges.

Runnel watches every result. When a test passes and fails on the same code, it’s quarantined: it still runs and reports, but it can’t turn a PR red. You get a ticket, not a re-run button.

  • Threshold 3 flips in 20 runs
  • Release automatic after 50 clean runs
